To run the demo, use the following steps:

1. docker compose up -d
2. docker ps
3. python -m venv venv
4. venv\Scripts\activate
5. pip install -r requirements.txt
6. python -m uvicorn main:app --reload

After step 6, open a second terminal 

7. cd to where the program is located
8. venv\Scripts\activate
9. pip install -r requirements.txt
10. python demo.py
11. curl http://127.0.0.1:8000/audit/jobs/UUID (Swap UUID with the actual value of the UUID from the program)
12. docker compose down
