# Information to access the database using PostgreSQL.

## Steps
1. Download PostgreSQL (https://www.postgresql.org/download/)
2. Open SQL Shell (.sql) 
3. Enter database information below.
```
Server [localhost]: localhost
Database [postgres]: gmap
Port [5432]: 5432
Username [postgres]: postgres
Password for user postgres: gmap
```
5. Use a code editor to connect to the database (VSCode, JetBrains, etc.)
6. Add PostgreSQL extensions within the code editor.
7. Download the *DB local.session.sql* file from the GitHub repo. Alternatively, clone the GitHub repository using the **git clone** https://github.com/ameyadeshmukh/GMAP.git command.
